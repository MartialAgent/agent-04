# 1단계 — 깃허브(GitHub) 시작하기

## 1. 깃(Git)과 깃허브(GitHub)는 뭐가 다른가?

| | 비유 |
|---|---|
| **Git** | 내 컴퓨터에 설치하는 **버전 관리 프로그램**. "문서의 모든 수정 이력을 자동 저장해주는 한글 파일" 같은 것 |
| **GitHub** | Git으로 관리하는 코드를 올려두는 **인터넷 저장소(클라우드)**. "코드 전용 구글 드라이브 + SNS" |

### 꼭 알아야 할 단어 5개

| 단어 | 뜻 |
|------|-----|
| **리포지토리(Repository, 리포)** | 프로젝트 폴더 하나. 지금 보고 있는 이것도 리포 |
| **커밋(Commit)** | "여기까지 작업했음"이라고 **저장 버튼 누르기** (메모도 남김) |
| **푸시(Push)** | 내 컴퓨터의 커밋을 **깃허브에 업로드** |
| **풀(Pull)** | 깃허브의 최신 내용을 **내 컴퓨터로 다운로드** |
| **클론(Clone)** | 깃허브의 리포를 **통째로 내 컴퓨터에 복사** (처음 한 번) |

> 흐름: **클론(처음 1번) → 수정 → 커밋 → 푸시** 반복. 다른 데서 수정된 게 있으면 **풀**.

## 2. VS Code에 깃허브 연동하기

1. VS Code 실행
2. 왼쪽 사이드바에서 **확장(Extensions, 네모 4개 아이콘)** 클릭
3. `GitHub Pull Requests` 익스텐션 검색 → **Install**
   - (Git 기능 자체는 VS Code에 기본 내장. 이 익스텐션은 깃허브 로그인/PR 기능 추가)
4. 왼쪽 하단 **계정 아이콘 → Sign in with GitHub** → 브라우저에서 로그인 허용

## 3. 이 리포 클론(끌어오기) 실습 🎯

1. `Ctrl + Shift + P` → **`Git: Clone`** 입력 → 엔터
2. Martial Agent가 알려준 리포 주소 붙여넣기: `https://github.com/MartialAgent/agent-ok.git`
3. 저장할 폴더 선택 → 완료되면 **Open** 클릭
4. 이 README가 보이면 성공! 🎉

## 4. 주요 명령어 (터미널 버전)

VS Code에서는 왼쪽 **소스 제어(가지 모양 아이콘)** 로 클릭만으로도 되지만,
터미널 명령어도 알아두면 좋습니다. (`` Ctrl + ` `` 백틱 키로 터미널 열기)

```bash
git clone <리포주소>      # 리포 통째로 복사 (처음 1번)
git status               # 지금 뭐가 바뀌었는지 확인
git add .                # 바뀐 파일 전부 커밋 대기줄에 올리기
git commit -m "메모"     # 저장! (메모는 한글로 써도 됨)
git push                 # 깃허브에 업로드
git pull                 # 깃허브 최신 내용 받아오기
git log --oneline        # 커밋 이력 한 줄씩 보기
```

### VS Code 클릭 버전 (더 쉬움)

1. 파일 수정
2. 왼쪽 **소스 제어** 아이콘 클릭 → 바뀐 파일 목록 확인
3. 파일 옆 **+** 클릭 (= `git add`)
4. 위 입력창에 메시지 쓰고 **✓ 커밋** 클릭 (= `git commit`)
5. **동기화(Sync) / 푸시** 버튼 클릭 (= `git push`)

## 5. cmd / PowerShell에서 클로드(Claude) 부르기

편집기 안에서만 작업할 필요는 없습니다. **명령 프롬프트(cmd)** 나 **PowerShell** 같은
터미널에서 바로 클로드를 불러 코드를 짜고 깃 작업까지 시킬 수 있습니다.

### 터미널이 뭔가?

마우스 클릭 대신 **글자(명령어)로 컴퓨터에 시키는 창**입니다. Windows에는 두 가지가 기본으로 있어요.

| 터미널 | 뭐가 다른가 |
|---|---|
| **cmd (명령 프롬프트)** | 옛날부터 있던 기본 터미널. 단순함 |
| **PowerShell** | cmd의 상위 버전. 기능이 더 많음. **오늘은 이걸 권장** |

> 여는 법: 시작 메뉴에서 `cmd` 또는 `powershell` 검색 → 실행.
> 또는 탐색기에서 폴더 열고 주소창에 `powershell` 입력 후 엔터 (그 폴더에서 바로 열림).

### 클로드 코드(Claude Code) 설치 & 실행

```powershell
npm install -g @anthropic-ai/claude-code   # 설치 (처음 1번, Node.js 필요)
cd "내 프로젝트 폴더 경로"                    # 작업할 폴더로 이동
claude                                       # 클로드 실행!
```

- 실행하면 대화창이 뜹니다. **한글로 "이거 만들어줘"** 라고 말하면 파일을 만들고 고쳐줍니다.
- 끝낼 때는 `exit` 입력 또는 `Ctrl + C` 두 번.

### 기본 명령어 정리 (터미널 공통)

터미널에서 폴더를 옮겨다니고 파일을 확인하는 데 자주 쓰는 명령어입니다.

| 하고 싶은 것 | cmd | PowerShell |
|------|------|------------|
| 현재 폴더 위치 확인 | `cd` | `pwd` |
| 폴더 안 파일 목록 보기 | `dir` | `ls` (또는 `dir`) |
| 다른 폴더로 이동 | `cd 폴더이름` | `cd 폴더이름` |
| 상위 폴더로 이동 | `cd ..` | `cd ..` |
| 화면 지우기 | `cls` | `cls` (또는 `clear`) |
| 폴더 새로 만들기 | `mkdir 이름` | `mkdir 이름` |
| 지금 폴더를 탐색기로 열기 | `start .` | `start .` |

> 팁: 폴더/파일 이름은 앞 몇 글자만 치고 **`Tab` 키**를 누르면 자동완성됩니다.
> 경로에 띄어쓰기가 있으면 `cd "Agent Ok"` 처럼 **따옴표**로 감싸세요.

### 깃 명령어도 터미널에서 그대로

위 **4번**의 `git clone`, `git add`, `git commit`, `git push` 명령어를 cmd/PowerShell에서
똑같이 쓸 수 있습니다. 클로드에게 **"커밋하고 푸시해줘"** 라고 말로 시켜도 됩니다.

> 결론: **편집기든 터미널이든 깃허브는 똑같이 동작한다.** 그리고 터미널에서 클로드를 부르면
> 명령어를 다 외우지 않아도 **말로 시켜서** 처리할 수 있습니다.
