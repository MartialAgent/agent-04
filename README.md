## 🎯 오늘의 핵심 개념 3가지

1. **깃허브(GitHub)** — 코드를 저장하고, 버전을 관리하고, 다른 사람과 공유하는 곳.
2. **바이브 코딩(Vibe Coding)** — 코드를 한 줄 한 줄 직접 짜는 게 아니라, AI에게 "이런 거 만들어줘"라고 말하고 결과를 확인·수정하며 만드는 방식. **뭘 만들고 싶은지 정확히 말하는 능력**이 핵심.
3. **에이전트(Agent)** — 단순히 대답만 하는 챗봇이 아니라, **스스로 판단하고 여러 단계를 거쳐 일을 처리하는 AI 프로그램**.
