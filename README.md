# 🤖 에이전트 04기 — 기초 컴퓨터 교육

> 인공지능융합학회 **에이전트 04기** 원우를 위한 코딩 부트캠프 리포입니다.
> 강사: Martial Agent

## 👥 누구를 위한 리포인가

04기 원우는 **인공지능 석사과정** 학생이지만, 배경도 도메인도 전부 다릅니다.

- **개발자** — 코드는 익숙하지만 에이전트 구조는 처음
- **준개발자** — 파이썬을 읽을 수는 있고, 직접 짜는 건 아직
- **비개발자** — 자기 도메인 전문가. 코드는 이번이 처음

**세 부류가 같은 자료로 진도를 나갑니다.** 대신 절마다 난이도를 표시해뒀습니다.

| 표시 | 대상 | 할 일 |
|---|---|---|
| 🟢 | 전원 | 읽고 이해하기. 코딩 없음 |
| 🟡 | 전원 (권장) | 코드를 **복사해 실행**하고 값 바꿔보기 |
| 🔴 | 개발 트랙 | 보고 **직접 짜기**. 못 해도 진도에 지장 없음 |

> 🔴을 못 해도 괜찮습니다. 다만 🟢🟡은 전원이 합니다.
> **비개발자에게 이 수업의 목표는 "코드를 짜는 것"이 아니라 "무엇이 가능한지 판단할 수 있게 되는 것"입니다.**

도메인도 각자 다릅니다. 영업·행정·연구·제조·인사·마케팅 무엇이든,
**자기 도메인을 그대로 들고 오세요.** 실습의 내용물이 됩니다.

### 이 순서인 이유

```
심장 (도메인마다 다름)  →  껍데기 : 깃허브 · 화면 · 서버      ← 1~2단계
뼈대 (원우 전원 공통)   →  내용물 : 트랜스포머 · LLM · 에이전트  ← 3~5단계
```

껍데기를 먼저 만드는 이유는, **내용물이 아무리 좋아도 남이 못 쓰면 소용없기 때문**입니다.
3~5단계에서 배울 것은 원우 전원에게 똑같습니다. 각자 다른 건 **그걸 누가 어떻게 쓰느냐**뿐입니다.

## 🎯 핵심 개념 3가지

1. **깃허브(GitHub)** — 코드를 저장하고, 버전을 관리하고, 다른 사람과 공유하는 곳.
2. **바이브 코딩(Vibe Coding)** — 코드를 한 줄씩 직접 짜는 게 아니라, AI에게 "이런 거 만들어줘"라고 말하고 결과를 확인·수정하며 만드는 방식. **뭘 만들고 싶은지 정확히 말하는 능력**이 핵심입니다. 비개발자에게 특히 중요합니다.
3. **에이전트(Agent)** — 단순히 대답만 하는 챗봇이 아니라, **스스로 판단하고 도구를 써서 여러 단계로 일을 처리하는 AI 프로그램**.
