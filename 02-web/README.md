# 2단계 — 웹개발 바이브코딩: 픽셀아트 사이트 만들기

## 1. 프론트엔드 vs 백엔드

웹사이트는 크게 두 부분으로 나뉩니다.

| | 프론트엔드 (Frontend) | 백엔드 (Backend) |
|---|---|---|
| **뜻** | 사용자 눈에 **보이는 부분** | 뒤에서 **데이터를 처리하는 부분** |
| **비유** | 식당의 홀, 메뉴판, 인테리어 | 식당의 주방, 창고, 회계 |
| **언어** | HTML, CSS, JavaScript | Python, Java, Node.js 등 |
| **예시** | 버튼, 색깔, 애니메이션 | 로그인 확인, 성적 저장, 결제 |

### 프론트엔드 3총사

| 언어 | 역할 | 비유 |
|------|------|------|
| **HTML** | 뼈대 (제목, 버튼, 그림판이 "있다") | 건물의 골조 |
| **CSS** | 꾸미기 (색, 크기, 배치) | 인테리어 |
| **JavaScript** | 동작 (클릭하면 색칠된다) | 전기·수도 설비 |

> 오늘 만드는 픽셀아트 사이트는 **프론트엔드만으로** 완성됩니다.
> 서버(백엔드) 없이 파일 하나로 브라우저에서 바로 돌아가요.

## 2. 실습: 픽셀아트 사이트 띄워보기 🎯

[`pixel-art/`](pixel-art/) 폴더에 완성본이 들어있습니다.

### 실행 방법 (3가지 중 아무거나)

**방법 A — 그냥 더블클릭 (가장 쉬움)**
탐색기에서 `02-web/pixel-art/index.html` 더블클릭 → 브라우저에서 열림

**방법 B — VS Code Live Server (추천)**
1. 확장에서 `Live Server` 검색 → 설치
2. `index.html` 열고 오른쪽 아래 **Go Live** 클릭
3. 코드를 수정하면 브라우저가 **자동 새로고침** — 바이브코딩에 최적!

**방법 C — 파이썬 간이 서버 ("서버를 띄운다"가 뭔지 체험)**
```powershell
cd 02-web/pixel-art
python -m http.server 8000
```
브라우저에서 `http://localhost:8000` 접속.
`localhost` = 내 컴퓨터, `8000` = 포트 번호(문 번호).

### 사이트 기능
- 색을 골라 격자를 클릭/드래그해서 픽셀아트 그리기
- 격자 크기 변경 (8×8 / 16×16 / 32×32)
- 지우개, 전체 지우기
- **PNG 파일로 저장** ← 그린 그림을 이미지 파일로 뽑아내기

## 3. 코드 훑어보기 (전부 이해 안 해도 됨!)

| 파일 | 역할 | 이것만 보기 |
|------|------|------------|
| `index.html` | 뼈대 | `<button>`, `<input type="color">` 태그가 화면 요소 하나하나와 대응 |
| `style.css` | 꾸미기 | `background:` 값을 바꾸고 저장해보기 → 색이 바뀜 |
| `script.js` | 동작 | `downloadPNG()` 함수 — 그림을 파일로 만드는 부분 |

## 4. 바이브코딩 실습 🎨

AI(클로드, ChatGPT, 커서 등)에게 이렇게 요청해서 기능을 추가해보세요:

> "pixel-art 폴더의 픽셀아트 사이트에 ○○ 기능을 추가해줘"

추천 미션 (쉬운 순):
1. 배경색을 바꿔줘 / 제목을 바꿔줘
2. 최근 사용한 색 팔레트를 보여줘
3. 실행 취소(Ctrl+Z) 기능을 넣어줘
4. 무지개 랜덤 색칠 모드를 넣어줘

**바이브코딩 팁**: 한 번에 하나씩, 구체적으로 요청하고 → 브라우저에서 확인하고 → 마음에 안 들면 "이 부분을 이렇게 고쳐줘"라고 다시 요청.
