# 2-2단계 완성 예시 (정답지)

> ⚠️ **먼저 열지 마세요.** 이 폴더는 [`../docs/`](../docs/00-how-to-use.md)를 따라
> 직접 만들다가 **막혔을 때 펴보는 정답지**입니다.

## 돌려보기

**[`index.html`](index.html)을 더블클릭하세요. 그게 전부입니다.**

설치도, 터미널 명령도, 계정도, 인터넷도 필요 없습니다.

## 화면 한 장에 네 덩어리

채팅으로만 더듬는 게 아니라, **기능을 직접 눌러보고 대화도 하는** 구조입니다.

```
┌──────────────────────────────────────────────────────────────┐
│ 🤖 내 도메인 어시스턴트              [이름____] [입장]         │
├─────────────────────────────┬────────────────────────────────┤
│ 📦 사내 데이터 [더미]        │  💬 대화 [두뇌만 더미]          │
│   A-1023  브라켓   48  3일   │                                │
│   B-2041  힌지      0  3주   │    ...말풍선 + 근거 칩...       │
│   C-3077  개스킷    5  1주   │    ▸ 에이전트가 한 일 3단계     │
│   ↑ 누르면 도구가 바로 돈다   │                                │
│                             │                                │
│ 🔧 도구 [진짜]               │                                │
│   [A-1023] [lookup] [list]  │                                │
│   > 실행 결과…               │                                │
│                             │                                │
│ 🧠 에이전트가 걸어간 길       │                                │
│   시작 → 🧠think ⇄ ⚙️action → 끝  │  [입력창]        [보내기]  │
│   ① think 도구가 필요…        │                                │
└─────────────────────────────┴────────────────────────────────┘
```

### 🎯 이 화면의 핵심 — 왼쪽과 오른쪽을 비교하세요

| | 🔧 도구 패널 | 💬 대화 |
|---|---|---|
| 어떤 도구를 쓸지 | **내가** 고른다 | **에이전트가** 고른다 |
| 부르는 함수 | `lookup()` | `lookup()` — **같은 함수** |
| 그래서 이건 | 그냥 프로그램 | **에이전트** |

왼쪽 표에서 `B-2041`을 누르고, 오른쪽에 `B-2041 언제 들어와?`라고 쳐보세요.
**결과는 같습니다. 다른 건 누가 골랐느냐 뿐입니다.**

### 해볼 질문

| 질문 | 보게 되는 것 |
|---|---|
| `B-2041 언제 들어와?` | 그래프에 `think → action → think` 가 순서대로 켜짐 + 근거 칩 |
| `안녕?` | `think` 하나로 끝. **action이 안 켜짐** ← 갈림길의 다른 쪽 |
| `품번 목록 보여줘` | `list_codes` 도구 |
| `A-1023이랑 C-3077 재고 알려줘` | `action`이 두 번, 근거 칩 2개 |
| `Z-9999?` | "등록되지 않은 품번" — **지어내지 않음** |

> 🎯 **`B-2041 언제 들어와?` 와 `안녕?` 을 나란히 쳐보세요.**
> **같은 코드가 질문에 따라 다른 길을 갑니다.** 그게 갈림길(조건 분기)이고,
> 챗봇과 에이전트를 가르는 유일한 차이입니다.
>
> F12 → Console 탭을 열어두면 에이전트가 걸어간 길이 그대로 찍힙니다.
> ```
> 💬 질문: B-2041 언제 들어와?
>   🧠 [think] 판단 중...
>   ⚙️ [action] 도구 실행
>   🔧 [도구] lookup(B-2041)
>   🧠 [think] 판단 중...     ← 도구 결과를 들고 다시 판단 = 반복
> ```

### 로그인

이름만 적으면 통과하는 **더미**입니다. 비밀번호도, 확인도, 실패도 없습니다.

**어디에도 저장하지 않습니다.** 새로고침하거나 창을 닫으면 **바로 풀립니다.**
그래도 배울 건 다 배웁니다 — `[나가기]` 후 다른 이름으로 들어가보세요.
**사용자가 다르면 대화방(thread)도 나뉩니다.**

## 이 폴더에 뭐가 있나

**돌아가는 것 — 브라우저 안에서 전부 끝납니다**

| 파일 | 역할 |
|---|---|
| [`index.html`](index.html) | 한 화면 — 데이터 · 도구 · 대화 · 그래프 |
| [`style.css`](style.css) | 2-1 + 배치 · 그래프 · 진행과정 · 근거칩 |
| [`script.js`](script.js) | 화면 동작 — 표 그리기, 도구 실행, 그래프 재생, 대화방 관리 |
| [`agent.js`](agent.js) | **그래프** — 노드 · 엣지 · 상태 · 조건분기 · 반복 |
| [`brain.js`](brain.js) | **판단** — ★ 여기가 진짜 LLM이 들어갈 자리 |
| [`data.js`](data.js) | **더미 사내 데이터** — 원우가 갈아끼우는 곳 |

**읽을 것 — 진짜 서버로 만들면 이렇게 됩니다**

같은 내용을 파이썬으로 옮긴 것입니다. **실행할 필요는 없습니다. 나란히 열어 비교해보세요.**

| 파일 | 짝 | 무엇을 보여주나 |
|---|---|---|
| [`app.py`](app.py) | (없음) | FastAPI 서버 — `@app.post("/api/chat")` 한 줄이 함수에 주소를 붙인다 |
| [`agent.py`](agent.py) | `agent.js` | 같은 그래프를 **LangGraph**로. `add_conditional_edges` · `add_edge` |
| [`brain.py`](brain.py) | `brain.js` | 같은 판단 로직 |
| [`data.py`](data.py) | `data.js` | 같은 더미 데이터 |
| [`requirements.txt`](requirements.txt) | | `fastapi` · `uvicorn` · `langgraph` |

> 💡 **`agent.js` 와 `agent.py` 를 나란히 놓고 보세요.**
> ```
> agent.py :  graph.add_conditional_edges("think", route, {...})   ← 선언한다
> agent.js :  while (true) { ... if (route() === END) break; }      ← 직접 돈다
> ```
> 하는 일은 똑같습니다. 선언해두면 나중에 중단·재개·병렬·기록이 공짜로 따라옵니다.
> **그게 LangGraph를 쓰는 이유**이고, 3~5단계에서 다시 만납니다.

## ★ 여기서 진짜인 것 / 가짜인 것

| | 진짜 | 가짜 (더미) |
|---|---|---|
| 그래프 구조 (노드·엣지·상태·조건분기·반복) | ✅ | |
| 도구를 쓰고 근거를 남기는 방식 | ✅ | |
| 화면이 진행 과정과 근거를 보여주는 방식 | ✅ | |
| 판단하는 두뇌 | | ❌ `brain.js`의 if 문 |
| 사내 데이터 | | ❌ `data.js`의 표 |
| 로그인 | | ❌ 이름만 적으면 통과 |

**API 키도 `.env`도 외부 통신도 없습니다.** 랜선을 뽑아도 끝까지 돌아갑니다.

3~5단계에서 진짜 LLM을 붙일 때 **바뀌는 건 `brain.js`(→`brain.py`) 하나뿐입니다.**

## 지금 이 예제의 한계

| 해볼 것 | 보게 되는 것 |
|---|---|
| **F12 → Sources → `data.js`** | 사내 데이터가 **누구에게나 다 보인다** |
| **`F5` 새로고침** | 대화도 로그인도 **전부 사라진다** |
| 다른 사람 컴퓨터에서 열기 | **내 대화가 없다** (내 브라우저 안에만 있었으니까) |

> 🎯 이 셋을 해결하는 게 **서버**이고, 그 모습이 옆의 [`app.py`](app.py)입니다.
> 지금은 **에이전트가 어떻게 도는지**를 보는 게 목적이라 서버 없이 끝냈습니다.
