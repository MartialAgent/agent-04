## 이 폴더에서 만드는 것

**수업용 에이전트 껍데기.** 2-1단계의 채팅창 뒤에 LangGraph 에이전트를 넣습니다.
목적은 **에이전트의 구조(노드·엣지·상태·조건분기·반복)를 눈으로 보는 것**입니다.
동작하는 것보다 **읽고 이해되는 것**이 우선입니다.

## 무엇이 진짜이고 무엇이 더미인가 ★

| 진짜로 만들 것 | 더미로 만들 것 |
|---|---|
| LangGraph 그래프 구조 | 판단하는 두뇌 (`brain.py` — 규칙 기반) |
| FastAPI 서버와 API 계약 | 사내 데이터 (`data.py` — 딕셔너리) |
| 도구 호출 흐름 | 로그인 (이름만 적으면 통과) |
| 화면과 상태 관리 | |

**더미인 것은 코드 주석과 화면에 "더미다"라고 분명히 밝히세요.** 숨기지 마세요.

## 절대 하지 말 것

- **LLM 호출** — `langchain-google-genai`, `openai`, `anthropic` 등 설치도 import도 금지
- **API 키, `.env`, 외부 네트워크 통신** — 인터넷 없이 돌아가야 합니다
- **진짜 인증** — 비밀번호 해시, JWT 라이브러리, OAuth 금지. 더미로 자리만
- **데이터베이스** — 서버 메모리로 충분
- **React, Vue, Tailwind, CDN, 빌드 도구**
- **스트리밍 응답** (`StreamingResponse`, SSE) — 구조가 복잡해집니다
- **멀티 에이전트, 서브그래프** — 4단계 소재입니다
- **시키지 않은 기능 추가** — 다음 STEP의 소재를 미리 써버리지 마세요

> 위 중 하나가 정말 필요해 보이면, **넣지 말고 먼저 물어보세요.**

## ★ 프론트/백 경계를 반드시 지킬 것

이 단계는 **프론트 한 번, 백 한 번씩 번갈아** 진행합니다.

| STEP | 고쳐도 되는 파일 | **건드리면 안 되는 파일** |
|---|---|---|
| 1 🔧 백 | `app.py` `agent.py` `brain.py` `data.py` `requirements.txt` | `index.html` `style.css` `script.js` |
| 2 🖥 프론트 | `index.html` `style.css` `script.js` | 백엔드 전부 |
| 3 🔧 백 | 백엔드 | 프론트 전부 |
| 4 🖥 프론트 | 프론트 | 백엔드 전부 |
| 5 🔧 백 | 백엔드 | 프론트 전부 |
| 6 🖥 프론트 | 프론트 | 백엔드 전부 |

> **이건 스타일 취향이 아니라 이 수업의 교재입니다.**
> "백엔드가 더 많이 알려주니까 화면이 더 많이 보여줄 수 있게 된다"를
> 눈으로 보여주는 게 목적입니다. 경계를 넘으면 그게 안 보입니다.
>
> 프론트 STEP인데 백엔드를 고쳐야 할 것 같으면, **고치지 말고 그 사실을 알려주세요.**

## 반드시 지킬 것

- **파일 역할 분리** (`02-spec.md` 1절)
  - `app.py` = HTTP만. 에이전트 안을 모른다
  - `agent.py` = 그래프만. 판단은 `brain`에게 맡긴다
  - `brain.py` = 판단만. 도구를 직접 실행하지 않는다
  - `data.py` = 값만
- **`brain.decide()`의 계약 고정** — `{"tool_calls": [...]}` 또는 `{"content": "..."}`
  (`02-spec.md` 4절. 진짜 LLM과 같은 모양이라 나중에 갈아끼울 수 있습니다)
- **도구가 돌려주는 모양 고정** — `{"text": ..., "sources": [...]}`
- **API 계약 고정** (`02-spec.md` 7절)
- **도구는 없는 데이터를 지어내지 않는다.** 없으면 없다고 답한다
- **주소·헤더에 넣는 값은 영문·숫자로.** 한글은 JSON 본문으로만
- 주석은 한국어로 넉넉하게. **무엇이 더미인지 반드시 명시**
- `innerHTML` 대신 `textContent`

## 파일 맨 위에 꼭 넣을 주석

- `agent.py` — 그래프 그림 (`think` / `action` / 조건분기 / 반복 화살표)
- `brain.py` — **"여기가 진짜 LLM이 들어갈 자리다. 지금은 규칙으로 흉내낸다.
  3~5단계에서 이 파일만 바꾸면 나머지는 그대로 돌아간다."**
- `app.py` — **2-1에는 서버가 없었다.** 서버가 왜 필요해졌는지 (감출 수 없다 / 남길 수 없다)
- `script.js` — 2-1단계에서 무엇이 늘었는지 (STEP 2·4·6)
