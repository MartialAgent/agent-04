# 2-2단계 문서 폴더 — 이걸 어떻게 쓰나

🟢 **전원** — 5분. 먼저 이것부터 읽으세요.

---

## 1. 2-1단계와 뭐가 다른가

**폴더 구조와 진행 방식은 똑같습니다.**

```
docs/     ← 지금 여기. 무엇을 만들지 적힌 문서
work/     ← 결과물이 쌓이는 곳
example/  ← 정답지 (막혔을 때만 편다)
```

**다른 것은 두 가지입니다.**

### ① 출발점이 빈 폴더가 아닙니다

2-1단계에서 만든 채팅창을 **그대로 가져와서 시작**합니다.
새 화면을 만들지 않습니다. **뒤에 두뇌를 넣는 것**이 이 단계입니다.

### ② 프론트와 백을 **번갈아** 만듭니다

| STEP | 어디를 | 무엇을 |
|---|---|---|
| 1 | 🔧 **백엔드** | 규칙표 → 에이전트로 교체 |
| 2 | 🖥 **프론트** | 에이전트가 한 일을 화면에 표시 |
| 3 | 🔧 **백엔드** | 도구 추가 + 근거(출처) 반환 |
| 4 | 🖥 **프론트** | 근거를 칩으로 표시 |
| 5 | 🔧 **백엔드** | 더미 로그인 + 대화방 분리 |
| 6 | 🖥 **프론트** | 로그인 화면 + 대화 이어가기 |

> 🎯 **이 번갈아 가는 리듬이 이 단계의 교재입니다.**
>
> 백엔드에 뭔가를 더하면 → **화면에 새 기능이 생깁니다.**
> 그런데 잘 보면 **프론트가 똑똑해진 게 아닙니다.**
> **서버가 더 많이 알려주니까 화면이 더 많이 보여줄 수 있게 된 것**뿐입니다.
>
> 이게 "화면과 두뇌는 분리되어 있다"는 말의 진짜 의미입니다.

## 2. 여기서 진짜인 것 / 가짜인 것 ★

**꼭 읽고 넘어가세요.** 나중에 헷갈립니다.

| | 진짜 | 가짜 (더미) |
|---|---|---|
| 그래프 구조 (노드·엣지·상태·조건분기·반복) | ✅ 진짜 LangGraph | |
| 서버·API·화면 | ✅ 진짜 | |
| 도구를 쓰고 결과를 받아 답하는 흐름 | ✅ 진짜 | |
| **판단하는 두뇌** | | ❌ `brain.py`의 if 문 |
| **조회하는 사내 데이터** | | ❌ `data.py`의 딕셔너리 |
| **로그인** | | ❌ 이름만 적으면 통과 |

### 왜 두뇌를 가짜로 하나

2단계의 목표는 **껍데기(화면·서버·구조)를 손에 쥐는 것**입니다.
여기서 API 키를 요구하면 전원이 키 발급·과금·네트워크 오류에서 시간을 다 씁니다.

**진짜 LLM은 3~5단계에서 붙입니다.** 그때 바뀌는 건 `brain.py` 파일 하나뿐입니다.
나머지는 한 줄도 안 고칩니다. 그래서 지금 구조를 제대로 만들어두는 게 의미가 있습니다.

> 💡 **이게 오히려 배우기 좋은 이유가 하나 더 있습니다.**
> 진짜 LLM은 같은 질문에 매번 다르게 답합니다. 규칙 기반은 **항상 똑같이 답합니다.**
> 그래서 "내가 코드를 잘못 짠 건지, 모델이 딴소리를 한 건지" 헷갈릴 일이 없습니다.

## 4. 시작 절차

### ① 2-1단계 결과물 가져오기 — **화면 세 개만**

```
02-web/01-web-basic/work/ 의 index.html, style.css, script.js 를
02-web/02-web-goal/work/ 로 복사해줘.

data.js 는 가져오지 마. 2-2단계에서는 그 표가 서버로 이사간다.
index.html에서 data.js 를 부르던 <script> 줄도 지워줘.
```

> ★ **2-1에는 서버가 없었습니다.** 가져올 파이썬 파일이 없는 게 정상입니다.
> **서버는 이 단계에서 처음 만듭니다.** 그게 2-1과 2-2를 나눈 이유입니다.
>
> 2-1단계를 못 했거나 결과물이 망가졌으면
> `02-web/02-web-goal/example/` 의 화면 파일 셋을 가져다 써도 됩니다. 부끄러운 일이 아닙니다.

### ② 문서 읽히기

```
02-web/02-web-goal/docs/ 폴더의 01-prd.md, 02-spec.md, 05-claude-rules.md 를 읽어줘.
그리고 05-claude-rules.md 를 02-web/02-web-goal/work/CLAUDE.md 로 복사해줘.

아직 코드는 만들지 마. "무엇을 만들 건지"를 세 줄로 요약해줘.
```

### ③ STEP 1부터 하나씩

[`03-steps.md`](03-steps.md)로 가세요.

## 5. 지켜야 할 것

1. **한 번에 한 STEP.** 백엔드 두 개를 몰아서 하면 화면에 뭐가 왜 생겼는지 안 보입니다.
2. **백엔드 STEP이 끝나면 F12 → Network 탭에서 응답 JSON을 먼저 보세요.**
   화면에 아직 안 보여도 **데이터는 이미 와 있습니다.** 그걸 확인하고 프론트 STEP으로 갑니다.
3. **에러는 빨간 글씨를 통째로 복사.** 요약하지 마세요.
