## A. 돌아가는가 (동작 검수) 🟢

http://localhost:8000 을 연 상태로.

- [ ] 로그인 화면이 먼저 뜨고, 이름을 넣으면 채팅으로 넘어간다
- [ ] `B-2041 언제 들어와?` → 재고 0개 · 납기 3주
- [ ] `품번 목록 보여줘` → 세 품번이 다 나온다
- [ ] `A-1023이랑 C-3077 재고 알려줘` → 두 개가 한 번에 조회된다
- [ ] `Z-9999?` → **"등록되지 않은 품번"** — 숫자를 지어내지 않는다
- [ ] `안녕?` → 도구 없이 바로 답한다
- [ ] 답변 아래 **진행 과정**이 접힌 채로 보이고, 클릭하면 펴진다
- [ ] 답변 아래 **근거 칩**(📄)이 보인다
- [ ] **`F5` 새로고침** → 로그인 없이 바로 채팅, 대화도 진행 과정도 그대로
- [ ] **[새 대화]** 를 누르면 비워진다
- [ ] 다른 이름으로 로그인하면 **대화가 비어 있다**
- [ ] 원래 이름으로 돌아오면 **대화가 그대로 있다**
- [ ] 서버를 끄고 메시지를 보내면 빨간 오류 말풍선이 뜬다

## B. 두 갈래를 다 봤는가 ★ 🟡

**에이전트의 핵심은 갈림길입니다. 두 길을 다 봐야 이해한 것입니다.**

- [ ] 도구를 **쓰는** 질문 → 터미널에 `think → action → think` 가 찍힌다
- [ ] 도구를 **안 쓰는** 질문 → `think` 한 번으로 끝난다
- [ ] 화면의 진행 과정에서도 그 차이가 보인다 (3단계 vs 1단계)

## C. 안 넣기로 한 걸 안 넣었는가 🟢

- [ ] `requirements.txt`에 **fastapi, uvicorn, langgraph 세 줄뿐**이다
- [ ] `langchain-google-genai` · `openai` 등 LLM 라이브러리가 **없다**
- [ ] `.env` 파일이 **없다**
- [ ] 코드 어디에도 **API 키가 없다**
- [ ] **인터넷을 끊어도** 정상 동작한다 ← ★ 직접 해보세요
- [ ] React·Tailwind·CDN이 **없다**
- [ ] 화면에 **"진짜 로그인이 아닙니다"** 안내가 표시되어 있다
- [ ] `brain.py` 맨 위에 **"여기가 진짜 LLM 자리"** 라는 주석이 있다

## D. 프론트/백 경계를 지켰는가 🟡

**이 단계의 리듬이 지켜졌는지 확인하는 항목입니다.**

- [ ] STEP 1(백)에서 `script.js`를 안 건드렸다
- [ ] STEP 2(프론트)에서 `agent.py`·`app.py`를 안 건드렸다
- [ ] STEP 3(백)에서 프론트를 안 건드렸다
- [ ] STEP 4(프론트)에서 백을 안 건드렸다
- [ ] **STEP 1이 끝났을 때 Network 탭에 `steps`가 이미 와 있는 걸 봤다** ← ★

## E. 왜 그런지 아는가 (이해 검수) 🟡

**가장 중요한 항목입니다.** 옆 사람에게 말로 설명해보세요.

- [ ] **챗봇과 에이전트의 차이**를 설명할 수 있다
- [ ] **노드 / 엣지 / 상태**를 한 문장씩 설명할 수 있다
- [ ] **갈림길(조건 분기)** 과 **되돌아가는 화살표(반복)** 를 `agent.py`에서 짚을 수 있다
- [ ] `brain.py`가 돌려주는 **두 가지 모양**(`tool_calls` / `content`)을 말할 수 있다
- [ ] **"프론트가 똑똑해진 게 아니라 백이 더 알려준 것"** 을 STEP 1→2로 설명할 수 있다 ← ★
- [ ] 근거 칩이 **있을 때와 없을 때**가 각각 무슨 뜻인지 설명할 수 있다
- [ ] 인증의 뼈대 세 단계(토큰 발급 → 헤더에 실어 보냄 → 서버가 확인)를 말할 수 있다
- [ ] **토큰에 한글을 못 쓰는 이유**를 설명할 수 있다
- [ ] 대화가 **서버 메모리에 있는 것과 DB에 있는 것의 차이**를 설명할 수 있다
- [ ] **이 프로젝트에서 무엇이 진짜이고 무엇이 더미인지** 목록으로 말할 수 있다 ← ★
- [ ] 3~5단계에서 진짜 LLM을 붙일 때 **어느 파일을 바꾸는지** 안다

## 실전 서비스와 비교 — Agent Room

관점은 **"우리는 장난감이고 저긴 진짜다"(단절)가 아니라
"구조가 같고 규모만 크다"(확장)** 입니다.

| | 내가 만든 껍데기 | Agent Room ([agentroom.cloud](https://agentroom.cloud)) |
|---|---|---|
| 화면 | `index.html` 한 장 + 바닐라 JS | Django 템플릿 + 바닐라 JS |
| 서버 | FastAPI, 엔드포인트 4개 | Python + Django |
| 판단 | `brain.py` 규칙 (더미) | **Gemini** |
| 흐름 | LangGraph 노드 2개 | **LangGraph 다중 에이전트** |
| 도구 | 2개 (더미 딕셔너리 조회) | 여러 개 (DB·외부 API) |
| 대화 기억 | 서버 메모리 (끄면 사라짐) | **PostgreSQL 영구 저장** |
| 로그인 | 이름만 적으면 통과 | **Django 세션 + 구글 OAuth** |
| 배포 | `localhost` | **Gunicorn → AWS EC2** |
| 결제 | 없음 | **Paddle 웹훅** |

> 오른쪽 열은 전부 왼쪽 열에 **하나씩 더한 것**입니다.
> 없던 개념이 아니라 **같은 자리의 확장판**입니다.
> 여러분은 이미 그 자리들을 전부 손으로 만들어봤습니다.
