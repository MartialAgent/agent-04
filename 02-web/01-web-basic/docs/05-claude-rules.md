## 이 폴더에서 만드는 것

**수업용 채팅창.** 웹이 처음인 사람이 **HTML·CSS·JavaScript·서버의 역할 차이를 눈으로 보는 것**이 목적입니다.
동작하는 것보다 **읽고 이해되는 것**이 우선입니다.

## 절대 하지 말 것

- **React, Vue, Svelte, Next.js 등 프레임워크** — 부품이 안 보이게 됩니다
- **Tailwind, Bootstrap 등 CSS 라이브러리, 모든 CDN 링크** — CSS가 무슨 일을 하는지 안 보이게 됩니다
- **빌드 도구** (npm, vite, webpack) — 설치에서 시간을 다 씁니다
- **API 키, `.env`, 외부 서비스 호출** — 이 단계는 인터넷 없이 돌아가야 합니다
- **AI·LLM 호출** — 두뇌는 2-2단계입니다
- **로그인, 회원가입, 데이터베이스** — 2-2단계 소재입니다
- **파일을 하나로 합치기** — 셋으로 나뉜 게 교재입니다
- **시키지 않은 기능 추가** — 다음 STEP의 소재를 미리 써버리지 마세요

> 위 중 하나가 정말 필요해 보이면, **넣지 말고 먼저 물어보세요.**

## 반드시 지킬 것

- **바닐라** HTML · CSS · JavaScript. 백엔드는 FastAPI + uvicorn만
- **한 번에 한 STEP.** 다음 STEP 내용을 미리 만들지 않습니다
- **파일 구성 고정** — `index.html` `style.css` `script.js` `server.py` `requirements.txt`
- **`id` 이름 고정** — `messages` `chat-form` `input` `send`
  (`02-spec.md` 3절. 바꾸면 문서와 어긋납니다)
- **API 계약 고정** — `POST /api/chat` 은 `{"question"}` → `{"answer"}`
  (`02-spec.md` 4절)
- **정적 파일 마운트는 `server.py` 맨 아래**
- **주석은 한국어로 넉넉하게.** 이 코드는 읽히려고 존재합니다
- 사용자 입력을 화면에 넣을 땐 **`innerHTML`이 아니라 `textContent`**

## 코드 스타일

- 변수·함수 이름은 영어, 설명은 한국어
- 한 함수는 화면 한 번에 들어올 정도로
- 영리한 축약보다 **길더라도 읽히는 쪽**
- 파일 맨 위에 "이 파일이 뭘 하는 파일인지" 주석 블록
