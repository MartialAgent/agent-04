> 만들었다고 끝이 아닙니다. **직접 눌러보고 확인한 것만 체크하세요.**

---

## A. 돌아가는가 (동작 검수) 🟢

브라우저에서 **http://localhost:8000** 을 연 상태로.

- [ ] 채팅창이 화면 가운데에 뜬다
- [ ] 메시지를 보내면 내 말풍선이 **오른쪽**에 붙는다
- [ ] 잠시 뒤 답변 말풍선이 **왼쪽**에 나타난다
- [ ] 빈 입력으로 보내기를 누르면 **아무 일도 안 일어난다**
- [ ] `Enter`로 보내지고, `Shift+Enter`로 줄바꿈된다
- [ ] 메시지를 많이 쌓으면 대화 영역**만** 스크롤되고 입력창은 제자리에 있다
- [ ] 답을 기다리는 동안 `"🤔 생각 중..."` 이 보인다
- [ ] 답을 기다리는 동안 버튼이 눌리지 않는다
- [ ] **`F5` 새로고침 → 대화가 남아 있다**
- [ ] 터미널에서 서버를 끄고 메시지를 보내면 **빨간 오류 말풍선**이 뜬다
- [ ] 서버를 다시 켜면 다시 정상 동작한다

## B. 안 넣기로 한 걸 안 넣었는가 🟢

`work/` 폴더를 열어서 확인하세요.

- [ ] 만든 파일이 **다섯 개**다 (`index.html` `style.css` `script.js` `server.py` `requirements.txt`)
  - `CLAUDE.md`(규칙)와 `README.md`(안내)는 원래 있던 것이니 세지 않습니다
  - 그 외에 못 보던 파일이 있으면 클로드에게 "이건 왜 만들었어?"라고 물어보세요
- [ ] `requirements.txt`에 **fastapi와 uvicorn 두 줄뿐**이다
- [ ] `.env` 파일이 **없다**
- [ ] 코드 어디에도 **API 키가 없다**
- [ ] React·Vue·Tailwind·Bootstrap·CDN 링크가 **없다**
- [ ] 로그인·회원가입 화면이 **없다**
- [ ] 인터넷을 끊어도 정상 동작한다

> 하나라도 걸리면 클로드에게: `"○○를 쓰지 않기로 했는데 들어가 있어. 걷어내줘."`

## C. 왜 그런지 아는가 (이해 검수) 🟡

**가장 중요한 항목입니다.** 옆 사람에게 말로 설명해보세요. 막히면 그 자리가 아직 안 넘어간 곳입니다.

- [ ] HTML / CSS / JavaScript 가 각각 뭘 맡는지 **한 문장씩** 말할 수 있다
- [ ] STEP 1 화면이 왜 못생겼는지, 그런데도 왜 "페이지가 존재한다"고 하는지 설명할 수 있다
- [ ] `id`가 왜 필요한지 설명할 수 있다 (`index.html` ↔ `script.js`의 짝)
- [ ] 프론트엔드와 백엔드를 **식당 비유**(홀 / 주방)로 설명할 수 있다
- [ ] **STEP 4에서 무엇이 불편했고, STEP 5가 그중 무엇을 해결했는지** 말할 수 있다 ← ★
- [ ] `@app.post("/api/chat")` 한 줄이 무슨 일을 하는지 설명할 수 있다
- [ ] API 키를 왜 `script.js`에 두면 안 되는지 설명할 수 있다
- [ ] 브라우저 메모리 / 서버 메모리 / 데이터베이스의 차이를 설명할 수 있다

## D. 개발자 도구를 써봤는가 🟢

- [ ] **F12 → Console 탭**을 열어봤다
- [ ] **F12 → Sources 탭**에서 `script.js`가 통째로 보이는 걸 확인했다 (STEP 4의 교훈)
- [ ] **F12 → Network 탭**에서 `chat` 요청의 `Payload`와 `Response`를 봤다 ← ★
- [ ] 에러가 났을 때 빨간 글씨를 **그대로 복사해서** 클로드에게 붙여넣어봤다

## E. 내 것으로 만들었는가 🟡

- [ ] 제목을 내 도메인으로 바꿨다
- [ ] `style.css`의 색을 한 번이라도 바꿔봤다
- [ ] `server.py`의 답변 규칙에 **내 업무 질문**을 하나 이상 추가했다
- [ ] [`01-prd.md`](01-prd.md) 7절 표의 **맨 아랫줄(내 도메인)** 을 채웠다
