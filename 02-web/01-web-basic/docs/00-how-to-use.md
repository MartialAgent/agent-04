# 2-1단계 문서 폴더 — 이걸 어떻게 쓰나

🟢 **전원** — 5분. 코딩 없습니다. 먼저 이것부터 읽으세요.

---

## 1. 이 폴더의 정체

이 폴더는 **설명서가 아니라 발주서**입니다.

여러분이 코드를 한 줄씩 타이핑할 일은 없습니다.
**문서를 클로드에게 읽히고, 단계별 주문을 하나씩 넣으면** 결과물이 나옵니다.

```
docs/     ← 지금 여기. 무엇을 만들지 적힌 문서 (읽고, 클로드에게 시킨다)
work/     ← 결과물이 쌓이는 곳 (여러분이 만든 것)
example/  ← 정답지 (막혔을 때만 편다)
```

> ⚠️ **`example/`를 먼저 열지 마세요.**
> 정답지를 먼저 보면 "만들어봤다"가 아니라 "읽어봤다"로 끝납니다.
> 15분 넘게 막혔을 때만 펴세요.

---

## 2. 바이브코딩이 왜 문서부터인가

"채팅창 하나 만들어줘"라고 하면 클로드는 만들어줍니다. 그런데 **매번 다른 걸 만들어줍니다.**
React를 쓰기도 하고, 파일을 하나로 합치기도 하고, 갑자기 로그인을 붙이기도 합니다.

그래서 실무에서는 코드를 짜기 전에 문서를 먼저 씁니다.

| 문서 | 답하는 질문 | 파일 |
|---|---|---|
| **PRD** (Product Requirements Document) | **왜** 만드나, **누가** 쓰나, **무엇이** 되면 성공인가 | [`01-prd.md`](01-prd.md) |
| **SPEC** (명세) | **어떻게** 만드나 — 파일, 데이터 모양, 화면 요소 이름 | [`02-spec.md`](02-spec.md) |
| **STEPS** (작업 지시서) | **어떤 순서로** 시킬 것인가 | [`03-steps.md`](03-steps.md) |
| **CHECKLIST** | **다 됐는지** 어떻게 아나 | [`04-checklist.md`](04-checklist.md) |
| **RULES** | 클로드가 **넘지 말아야 할 선** | [`05-claude-rules.md`](05-claude-rules.md) |

> 💡 **비개발자에게 특히 중요합니다.**
> 코드를 못 짜도 상관없습니다. **뭘 원하는지 정확히 쓸 수 있으면 만들어집니다.**
> 이 수업에서 진짜로 연습하는 건 그 능력입니다.

---

## 3. 시작 절차

### ① 작업 폴더 만들기

VS Code에서 이 리포를 열고, 터미널에서 클로드를 부릅니다.

```powershell
claude
```

첫 주문은 이겁니다. **그대로 복사해서 붙여넣으세요.**

```
02-web/01-web-basic/docs/ 폴더의 문서를 전부 읽어줘.
01-prd.md, 02-spec.md, 03-steps.md, 05-claude-rules.md 네 개다.

읽고 나서 아직 코드는 만들지 마.
대신 "무엇을 만들 건지"를 세 줄로 요약해서 말해줘.
```

클로드의 요약이 여러분이 이해한 것과 다르면, **거기서 바로잡고 시작하세요.**
(그게 문서를 먼저 읽히는 이유입니다)

### ② 규칙 파일 놓기

```
02-web/01-web-basic/docs/05-claude-rules.md 를
02-web/01-web-basic/work/CLAUDE.md 로 복사해줘.
```

> 클로드는 작업 폴더의 `CLAUDE.md`를 자동으로 읽습니다.
> 대화가 길어져도 규칙을 잊지 않게 하는 장치입니다.

### ③ STEP 1부터 하나씩

[`03-steps.md`](03-steps.md)로 가서 **STEP 1의 프롬프트를 그대로 복사**해 넣으세요.
그리고 **확인**란을 직접 눈으로 확인한 뒤에 STEP 2로 갑니다.

---

## 4. 지켜야 할 것 딱 세 개

1. **한 번에 한 STEP.** 두 개를 몰아서 시키면 뭐 때문에 뭐가 달라졌는지 안 보입니다. 이 단계는 그걸 보는 게 전부입니다.
2. **매 STEP마다 브라우저에서 눈으로 확인.** 확인 안 하고 다음으로 넘어가면 어디서 틀어졌는지 나중에 못 찾습니다.
3. **에러는 빨간 글씨를 통째로 복사해서 붙여넣기.** 요약하지 마세요. F12 → Console 탭에 있습니다.

---

## 5. 막혔을 때

| 증상 | 해볼 것 |
|---|---|
| 화면이 아예 안 뜸 | 파일 경로가 맞는지, `index.html`을 열었는지 확인 |
| 스타일이 안 먹음 | `index.html`에 `<link ... style.css>` 줄이 있는지 |
| 버튼을 눌러도 반응 없음 | F12 → Console 탭에 빨간 글씨가 있는지 |
| 서버 연결 실패 | 터미널에 `uvicorn`이 아직 돌고 있는지 |
| 15분 넘게 안 됨 | [`../example/`](../example/README.md) 정답지와 비교 |

에러 메시지를 클로드에게 줄 땐 이 형식이 가장 잘 통합니다.

```
STEP 3을 했는데 이렇게 나와.

(F12 Console의 빨간 글씨 전체 붙여넣기)

내가 기대한 건 (무엇), 실제로는 (무엇)이 일어났어.
```
