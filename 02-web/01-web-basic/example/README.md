# 2-1단계 완성 예시 (정답지)

> ⚠️ **먼저 열지 마세요.** 이 폴더는 [`../docs/`](../docs/prd.md)를 따라
> 직접 만들다가 **막혔을 때 펴보는 정답지**입니다.
>
> 정답지를 먼저 보면 "만들어봤다"가 아니라 "읽어봤다"로 끝납니다.
> 15분 넘게 막혔을 때 펴세요.

## 돌려보기

**[`index.html`](index.html)을 더블클릭하세요. 그게 전부입니다.**

터미널 명령도, `pip install`도, 파이썬도, 인터넷도 필요 없습니다.
**랜선을 뽑고도 끝까지 돌아갑니다.**

**해볼 질문**

| 입력 | 보게 되는 것 |
|---|---|
| `A-1023 재고 얼마나 있어?` | 품번을 알아듣고 재고·납기·담당 |
| `힌지 언제 들어와?` | 품번 없이 **이름만으로도** 걸림 |
| `HELLO` | 대소문자를 안 가림 (`hello`와 같음) |
| `뭐 할 수 있어?` | 지금 답할 수 있는 것 목록 |
| `오늘 날씨 어때?` | **모른다고 솔직히** 답함 ← ★ 지어내지 않습니다 |

## 이 폴더에 뭐가 있나

| 파일 | 언제 생겼나 | 역할 |
|---|---|---|
| [`index.html`](index.html) | STEP 1 | 뼈대 — 무엇이 **있는가** |
| [`style.css`](style.css) | STEP 2 | 꾸미기 — 어떻게 **보이는가** |
| [`script.js`](script.js) | STEP 3~4 | 동작 — 무슨 일이 **일어나는가** |
| [`data.js`](data.js) | STEP 4 | 내용물 — **무엇을 답하는가** ← ★ |

여기 있는 건 **STEP 4까지 끝난 상태**입니다.
각 파일 맨 위 주석에 "어느 STEP에서 무엇이 추가됐는지"가 적혀 있습니다.

> **STEP 5(내 도메인으로 교체)는 일부러 안 해뒀습니다.** 그건 각자 다르니까요.
> [`data.js`](data.js)만 열어 여러분 업무 질문으로 바꿔보세요. **나머지 셋은 안 건드려도 됩니다.**

## 여기엔 **없는** 것

**서버 · 파이썬 · `fetch` · API 키 · `.env` · 로그인 · 데이터베이스 · 프레임워크 — 하나도 없습니다.**

파일을 다 뒤져도 `fetch`도 `http://`도 나오지 않습니다. 2-1단계는 **브라우저 안에서 끝납니다.**
2-2단계도 마찬가지로 브라우저 안에서 끝납니다.

> 결과물에 `server.py`나 `requirements.txt`가 생겼다면 **잘못 만든 것입니다.**
> [`../docs/frontend.md`](../docs/frontend.md)의 6절(넘지 말아야 할 선)을 다시 보세요.

## 꼭 직접 해보세요 — 이게 2-2로 가는 이유입니다

| 해볼 것 | 보게 되는 것 |
|---|---|
| **F12 → Sources → `data.js`** | 데이터가 **접속자 누구에게나 다 보인다** |
| **F12 → Network 탭**에서 메시지 보내기 | **아무 요청도 안 생긴다** (서버가 없다는 증거) |
| **`F5` 새로고침** | 나눈 대화가 **전부 사라진다** |

> 🎯 **화면만으로도 동작은 한다. 그런데 감출 수도 없고, 남길 수도 없다.**
> **그래서 서버가 필요하다.** — 이 감각을 안고 2-2단계로 갑니다.
> (2-2도 브라우저에서 끝냅니다. 서버의 모습은 읽을거리로만 봅니다)
