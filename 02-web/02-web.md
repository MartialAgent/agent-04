# 2단계 — 웹개발: 에이전트를 남이 쓰게 만들기

## 이 단계가 있는 이유

3~5단계에서 배울 **에이전트는 원우 전원에게 똑같습니다.** 파이썬도, 트랜스포머도, LangGraph도 도메인마다 다르지 않아요.

각자 다른 건 **그걸 누가, 어떻게 쓰느냐**입니다. 그리고 나중에 자기 도메인에 에이전트를 붙이려 할 때 전원이 똑같은 데서 막힙니다.

> "코드는 돌아간다. 그런데 이걸 어떻게 **우리 팀이 쓸 수 있는 물건**으로 만들지?"

2단계는 그 물음에 대한 최소 정답 하나를 손에 쥐어줍니다. 완성된 사이트를 만드는 게 아니라,
**내용물만 갈아끼우면 어떤 도메인에도 맞는 껍데기**를 만듭니다.

```
심장 (도메인마다 다름)  →  껍데기 : 도구 · 화면 · 서버     ← 2단계
뼈대 (원우 전원 공통)   →  내용물 : 파이썬 · LLM · 에이전트  ← 3~5단계
```

> 💡 **비개발자에게**: 이 단계가 이 수업에서 **가장 겁나 보이지만 실은 가장 안전한 구간**입니다.
> 코드는 전부 만들어져 있고, 여러분이 할 일은 **실행하고, 한 줄 바꾸고, 뭐가 달라지는지 보는 것**입니다.

## 2단계를 마치면

🟢
- [ ] 웹 서비스에 어떤 서비스(계정)들이 필요한지, 언제 필요한지 안다
- [ ] 화면이 HTML·CSS·JavaScript 세 부품의 조합이라는 걸 손으로 확인했다
- [ ] 화면과 서버가 분리되어 있고 JSON으로 대화한다는 걸 안다
- [ ] API 키를 어디에 둬야 하는지 안다
- [ ] **내 도메인의 입력값과 에이전트가 할 일을 한 줄로 적었다**

🟡
- [ ] 브라우저에서 내가 띄운 서버에 접속해봤다
- [ ] 가짜 응답 → 진짜 에이전트 전환을 직접 해봤다
