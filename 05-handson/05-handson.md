# 5단계 — 교사 업무 에이전트 돌려보기

## 이 단계는 코딩 없음! 실행만 해보세요 🏃

[`teacher_agent.py`](teacher_agent.py)는 Martial Agent가 미리 만들어둔 **교사 업무 도우미 에이전트**입니다.
4단계의 `tool_agent.py`와 같은 랭그래프인데, 노드가 몇 개 더 많을 뿐입니다.

## 무엇을 하나요?

교사의 요청을 받으면 에이전트가 **스스로 업무 종류를 판단**해서 알맞은 담당 노드로 보냅니다.

```
                          ┌─> [📄 가정통신문 작성 노드]
[요청 입력] ─> [분류 노드] ┼─> [✏️ 생활기록부 문구 노드]
                          ├─> [💡 수업 아이디어 노드]
                          └─> [💬 일반 상담 노드]
```

이 "스스로 판단해서 갈림길을 고르는 것"(조건 분기)이 챗봇과 에이전트의 차이입니다.

## 실행 방법 🎯

(.env 설정과 `pip install`은 4단계에서 이미 완료)

```powershell
python 05-handson/teacher_agent.py
```

## 이렇게 입력해보세요

- `다음 주 금요일 현장체험학습 가정통신문 써줘. 장소는 과학관, 준비물은 도시락.`
- `우리 반에 발표를 잘하고 친구를 잘 돕는 학생이 있어. 생기부 행동특성 문구 추천해줘.`
- `초등 5학년 과학, 태양계 단원 첫 수업 아이디어 3개만.`
- `요즘 업무가 너무 많아서 지쳐...`

각 답변 위에 **어느 노드가 처리했는지** 표시됩니다.
같은 프로그램인데 요청에 따라 다른 길로 가는 걸 확인해보세요.
